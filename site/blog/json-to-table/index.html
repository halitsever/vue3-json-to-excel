Turn JSON into a table you can read

By Halit Sever · 28 November 2026

A JSON array of records is already a table in disguise: every object is a row and every key is a column. The work is in deciding what happens to keys that only some records have, and to values that are objects or lists themselves.

How JSON maps to a table

Take two records from an orders API:

[
  { "id": 1001, "customer": "Acme", "paid": true, "shipping": { "city": "Berlin" }, "items": ["keyboard", "mouse"] },
  { "id": 1002, "customer": "Globex", "paid": false, "shipping": { "city": "Lyon" } }
]

As a table, it reads like this:

idcustomerpaidshipping.cityitems
1001AcmeTRUEBerlin["keyboard","mouse"]
1002GlobexFALSELyon
  • Each object is a row. A single object, not inside an array, gives a table with one row.
  • Columns are the union of all keys, in the order they first appear. A key that a record does not have leaves an empty cell.
  • Nested objects become dotted columns such as shipping.city, so nothing is hidden inside a cell.
  • Arrays stay in one cell as JSON text. Spreading a list over new rows would repeat every other value, which is rarely what you want in a first look.

Online: paste it into the converter

The JSON to Excel converter on this site shows a table preview as soon as you paste JSON or open a .json file. It follows exactly the rules above, because the preview and the .xlsx download use the same toRows() function from the vue3-json-to-excel package.

  1. Paste the JSON into the box, or upload the file.
  2. Read the row and column count above the table. The preview shows the first 50 rows.
  3. If you need all of it, or want to sort and filter, click Download .xlsx and open the file in Excel, Google Sheets or LibreOffice.

Everything runs in the browser, so the JSON is not uploaded anywhere. If the text is not valid JSON, the page shows the parser's error message instead of a table.

In Excel: Power Query

Excel for Microsoft 365 can load JSON into a table itself, under Data › Get Data › From File › From JSON. You expand records into columns step by step in the Power Query Editor, which gives you control over each nested field. The full steps are in how to open a JSON file in Excel.

In your own page: JSON to an HTML table

For a flat array of objects, building an HTML table in the browser takes a few lines. This version collects the columns from every record and uses textContent, so values from the JSON are never parsed as HTML: 

function jsonToTable(rows) {
  const columns = [...new Set(rows.flatMap((row) => Object.keys(row)))];
  const table = document.createElement('table');
  const head = table.createTHead().insertRow();
  for (const column of columns) {
    head.appendChild(document.createElement('th')).textContent = column;
  }
  const body = table.createTBody();
  for (const row of rows) {
    const tr = body.insertRow();
    for (const column of columns) {
      const value = row[column];
      tr.insertCell().textContent =
        value === undefined || value === null ? '' : typeof value === 'object' ? JSON.stringify(value) : String(value);
    }
  }
  return table;
}

const rows = await (await fetch('/orders.json')).json();
document.body.append(jsonToTable(rows));

Objects and arrays are written as JSON text here. To get dotted columns instead, flatten each record first. The package exports the function it uses for that: 

import { toRows } from 'vue3-json-to-excel';

document.body.append(jsonToTable(toRows(rows)));

How toRows() handles deeper nesting, empty objects and arrays of objects is covered in nested JSON to Excel.
