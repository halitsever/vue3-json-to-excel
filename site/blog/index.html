JSON and Excel guides

Short, tested guides for moving data between JSON and spreadsheets. The code samples were run against SheetJS 0.20.3, the version the JSON to Excel converter on this site uses.

  • How to open a JSON file in Excel

    Open a JSON file in Excel with Power Query: Get Data, From JSON, turn the list into a table and expand the columns. Plus a quicker route for one-off files.

  • How to open a JSON file

    A JSON file is plain text. Open it in a browser, a code editor or Notepad to read it, or turn it into an Excel table when you need rows and columns.

  • Sample JSON files to download and test

    Four small sample JSON files to download: a flat array, nested orders, a single object and an API-style response, with the table each one turns into.

  • How to convert JSON to CSV

    Convert JSON to CSV three ways: save the converted sheet from Excel, use SheetJS in JavaScript, or run jq. Plus what CSV loses compared to an .xlsx file.

  • Nested JSON to Excel: how objects and arrays become columns

    A sheet is flat and JSON is not. How nested objects become dotted columns, the two ways to handle arrays, and how to get the nested JSON back from Excel.

  • Convert Excel to JSON in JavaScript

    Read an .xlsx file in the browser or Node.js and turn a sheet into JSON with SheetJS sheet_to_json: headers, empty cells, dates and every option tested.

  • JSON to Excel in JavaScript with SheetJS

    Export a JSON array to an .xlsx file in JavaScript with SheetJS json_to_sheet: column order, widths, dates, nested objects and the browser download.

  • Vue 3 export to Excel: download JSON as an .xlsx file

    Add an Export to Excel button to a Vue 3 app with the vue3-json-to-excel component: install, props, reactive data, file names and a SheetJS version.
