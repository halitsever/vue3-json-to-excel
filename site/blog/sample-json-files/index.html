Sample JSON files to download and test

By Halit Sever · 27 November 2026

Four small JSON files for testing a parser, an import or a converter. Each one shows a shape you meet in real data, and for each I list what the JSON to Excel converter on this site makes of it.

1. A flat array of records

people.json (5 records). Every object has the same six keys and no nesting, the easiest shape for any tool. 

[
  { "id": 1, "name": "Ada Lovelace", "email": "ada@example.com", "country": "GB", "active": true, "joined": "2026-01-15" },
  { "id": 2, "name": "Grace Hopper", "email": "grace@example.com", "country": "US", "active": true, "joined": "2026-02-03" },
  ...
]

In the converter: 5 rows, 6 columns. id stays a number and active a boolean. joined is a string in the JSON, so it arrives in Excel as text, not as a date cell.

2. Nested objects and arrays

orders.json (3 orders). Each order has a shipping object and an items array, and one order has an empty array. 

{
  "order": 1001,
  "customer": "Acme Ltd",
  "total": 249.9,
  "paid": true,
  "shipping": { "city": "Berlin", "country": "DE" },
  "items": ["keyboard", "mouse"]
}

In the converter: 3 rows, 7 columns. shipping splits into shipping.city and shipping.country, and items stays in one cell as JSON text. The nested JSON guide explains the choices.

3. A single object

settings.json. A settings file is one object, not a list, with a nested object and a null. 

{
  "theme": "dark",
  "language": "en",
  "pageSize": 25,
  "notifications": { "email": true, "push": false },
  "beta": null
}

In the converter: 1 row, 6 columns, with notifications.email and notifications.push as their own columns. The beta cell is empty because null has no Excel value.

4. An API response with a wrapper

api-response.json. Paginated APIs often return the records inside a data array, next to paging fields. 

{
  "page": 1,
  "per_page": 3,
  "total": 3,
  "data": [
    { "id": "p-01", "title": "Desk lamp", "price": 34.5, "stock": 12, "tags": ["lighting", "office"] },
    ...
  ]
}

This one is a trap. The top level is an object, so the converter treats the whole file as one record: 1 row, 4 columns, with all products squeezed into the data cell as JSON text. To get one row per product, paste only the array that follows "data":. That gives 3 rows and 5 columns. Power Query in Excel has the same issue and solves it by drilling into the data list.

A sample Excel file for the other direction

people.xlsx holds the records from people.json in one sheet. Open it in the Excel to JSON converter to see the rows come back as JSON.

All files are made up for testing. The names belong to well-known mathematicians and computer scientists, and the email addresses use the reserved example.com domain.
