What is a JSON file?

By Halit Sever · 28 November 2026

A .json file holds data written in JSON, short for JavaScript Object Notation. It is plain text, so people can read it, and its rules are strict enough that every programming language can parse it the same way. That is why APIs, configuration files and data exports use it so often.

The format in one example

{
  "name": "vue3-json-to-excel",
  "version": "1.1.1",
  "private": false,
  "keywords": ["vue", "excel", "xlsx"],
  "author": { "name": "Halit Sever", "url": "https://halit.org" },
  "funding": null
}

JSON is defined in RFC 8259 and the ECMA-404 standard. A JSON text is one value, and there are six kinds of value:

TypeWritten asExample
ObjectKey and value pairs in curly braces{"city": "Berlin"}
ArrayAn ordered list in square brackets["vue", "excel"]
StringText in double quotes"Halit"
NumberDecimal, optional fraction and exponent9.5, -3, 1e3
BooleanThe bare wordstrue, false
NullThe bare wordnull

Objects and arrays can hold any of the six, so data can nest as deep as it needs to.

The rules that trip people up

  • Double quotes only. Keys and strings use ". Single quotes are a syntax error.
  • Keys are always strings, so {id: 1} is not JSON, but {"id": 1} is.
  • No comma after the last item in an object or array.
  • No comments. The grammar has no comment syntax. See comments in JSON for what to do instead.
  • No dates. There is no date type. Dates travel as strings, usually in ISO 8601 form such as "2026-11-28".
  • Numbers have no leading zeros, and NaN or Infinity are not allowed.

RFC 8259 also says JSON exchanged between systems must be encoded as UTF-8. Whitespace between values is ignored, so a file can be pretty-printed over many lines or packed onto one.

File extension and media type

JSON files end in .json, and servers send JSON with the media type application/json. Some tools use their own names for files that are JSON underneath, and some relax the rules: VS Code's settings.json, for example, accepts comments.

Where you will meet JSON files

  • Web APIs. Most REST APIs send and receive JSON. In JavaScript, response.json() and JSON.parse() turn it into objects (MDN reference).
  • Configuration. package.json in Node.js projects, tsconfig.json, browser extension manifests.
  • Exports. Many apps let you download your data as JSON, from analytics tools to social networks.

JSON, CSV or Excel?

JSON keeps structure and types: a nested address stays nested and true stays a boolean. CSV is a flat table of text. An .xlsx file is a flat table with types and formatting. When someone needs to scan, sort or filter JSON records, turning them into a table is usually the fastest way. The JSON to Excel converter does that in the browser, and how to open a JSON file lists the other options.
