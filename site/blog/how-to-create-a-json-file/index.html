How to create a JSON file

By Halit Sever · 28 November 2026

A JSON file is a plain text file with a .json extension and JSON inside. You can type one by hand in any text editor, export one from a spreadsheet, or have a program write it. The only real requirement is that the text follows JSON's rules.

In a text editor

Start with something small and valid:

[
  { "name": "Ada", "city": "London", "active": true },
  { "name": "Grace", "city": "New York", "active": false }
]

Windows: Notepad

  1. Open Notepad, paste or type the JSON.
  2. Choose File › Save as, set Save as type to All files and type a name ending in .json, such as people.json.
  3. Keep the encoding on UTF-8 and click Save.

Mac: TextEdit

  1. Open TextEdit and choose Format › Make Plain Text, so the file has no rich text formatting.
  2. Turn off smart quotes in Edit › Substitutions. Curly quotes are not valid JSON.
  3. Save with a name ending in .json. If TextEdit asks, choose Use .json.

Any system: a code editor

In Visual Studio Code, create a new file, save it as something.json and VS Code switches to JSON mode: it colours the syntax, underlines errors as you type and formats the file with Format Document.

From a spreadsheet

If your data is already in Excel or Google Sheets, there is no need to type it. Save or download it as .xlsx or .csv and open it in the Excel to JSON converter. The first row becomes the keys, every other row becomes an object, and you download the result as a .json file. The file never leaves your browser.

From code

Writing JSON from a program is safer than building the text by hand, because the serializer handles quotes, escapes and commas.

JavaScript (Node.js)

import { writeFileSync } from 'node:fs';

const people = [{ name: 'Ada', city: 'London', active: true }];
writeFileSync('people.json', JSON.stringify(people, null, 2) + '\n');

The third argument of JSON.stringify sets the indent. Values that JSON cannot hold are dropped from objects: undefined and functions disappear, and a Date becomes an ISO string.

Python

import json

people = [{"name": "Ada", "city": "London", "active": True}]
with open("people.json", "w", encoding="utf-8") as f:
    json.dump(people, f, ensure_ascii=False, indent=2)

Python writes True as true and None as null. ensure_ascii=False keeps letters such as ü as they are instead of \u00fc.

Check that it is valid

A missing quote or an extra comma makes the whole file unreadable for most programs. Paste the text into the JSON to Excel converter: valid JSON shows up as a table, and invalid JSON shows the parser's error message with the position. In a terminal, python3 -m json.tool people.json prints the file formatted, or the error if there is one.
