How to read a JSON file in Python

By Halit Sever · 28 November 2026

Python's standard library reads JSON with the json module, so there is nothing to install. Open the file, call json.load, and you get ordinary lists and dictionaries back.

The short version

Given a file people.json:

[
  { "name": "Ada Lovelace", "born": 1815, "active": true, "tags": ["math", "poetry"], "office": null },
  { "name": "Grace Hopper", "born": 1906, "active": false, "tags": ["navy"], "office": { "city": "Arlington" } }
]

read it like this:

import json

with open("people.json", encoding="utf-8") as f:
    people = json.load(f)

for person in people:
    print(person["name"], person["born"], person["active"], person["office"])

Output, from Python 3.14:

Ada Lovelace 1815 True None
Grace Hopper 1906 False {'city': 'Arlington'}

Pass encoding="utf-8" explicitly. JSON files are UTF-8, but open() otherwise uses the system's default encoding, which on some Windows setups is not UTF-8 and turns accented letters into errors or garbage.

This is the conversion table from the json module documentation. Dates stay strings, because JSON has no date type. Parse them with datetime.date.fromisoformat() when you need real dates.

json.load or json.loads?

  • json.load(f) reads from an open file.
  • json.loads(text) parses a string, for example the body of an HTTP response.
data = json.loads('{"price": 9.5, "n": 3}')
print(data)  # {'price': 9.5, 'n': 3}

The s stands for string. json.dump and json.dumps are the writing counterparts.

When the file will not load

Invalid JSON raises json.JSONDecodeError, which says what was expected and where:

try:
    json.loads("{'a': 1}")
except json.JSONDecodeError as e:
    print(e)  # Expecting property name enclosed in double quotes: line 1 column 2 (char 1)

The usual causes:

  • Single quotes, often from text that was printed from a Python dict instead of written with json.dump.
  • A trailing comma after the last item.
  • Comments, which JSON does not allow. See comments in JSON.
  • One JSON object per line (JSON Lines). Read those line by line with json.loads(line).

From JSON to a spreadsheet

With pandas installed, pandas.json_normalize flattens nested records into columns, and DataFrame.to_excel writes an .xlsx file (it needs the openpyxl package). For a one-off file, the JSON to Excel converter does the same in the browser with no code: nested objects get dotted columns such as office.city.
