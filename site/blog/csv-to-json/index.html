How to convert CSV to JSON

By Halit Sever · 28 November 2026

A CSV file is a table in plain text, and JSON for a table is an array of objects: one object per line, with the header row as the keys. The conversion is simple. The part worth checking is what each tool does with values that look like numbers or dates.

Online, without uploading the file

The Excel to JSON converter on this site also reads .csv files. SheetJS parses the file in your browser, so nothing is sent to a server.

  1. Open the converter and choose your .csv file.
  2. Tick Write empty cells as null if every object should have every key. Without it, empty cells are left out.
  3. Tick the nested option if your headers use dots, such as address.city, and you want nested objects back.
  4. Copy the JSON or download it as a .json file.

What happens to the values

CSV has no types: every value is text. A converter either keeps everything as strings or guesses. SheetJS guesses, and so does the converter above. We ran this file through SheetJS 0.20.3 with the same options the converter uses: 

id,name,price,active,joined,zip
1,Ada,9.50,TRUE,2026-11-02,02134
2,Grace,12,false,11/03/2026,
3,"Smith, Jo",7,TRUE,,90210

The result:

[
  { "id": 1, "name": "Ada", "price": 9.5, "active": true, "joined": "2026-11-02", "zip": 2134 },
  { "id": 2, "name": "Grace", "price": 12, "active": "false", "joined": "2026-11-03" },
  { "id": 3, "name": "Smith, Jo", "price": 7, "active": true, "zip": 90210 }
]
  • Numbers become JSON numbers, and 9.50 becomes 9.5.
  • TRUE and FALSE in capitals, the way Excel writes them, become booleans. Lowercase false stayed a string.
  • Dates become ISO dates. 11/03/2026 was read month first, as 3 November.
  • Leading zeros are lost: the postcode 02134 became the number 2134.
  • Quoted values keep their commas: "Smith, Jo" stays one value.

When codes, postcodes or IDs must stay exactly as written, read the file as text. In SheetJS that is the raw: true option of XLSX.read, shown below. With it, every value in the example stays a string, including "02134".

JavaScript with SheetJS

The same two calls work in Node.js and in the browser:

import * as XLSX from 'xlsx';
import { readFileSync, writeFileSync } from 'node:fs';

const book = XLSX.read(readFileSync('people.csv'), { cellDates: true });
const rows = XLSX.utils.sheet_to_json(book.Sheets[book.SheetNames[0]], { UTC: true });
writeFileSync('people.json', JSON.stringify(rows, null, 2));

A CSV file always has one sheet, named Sheet1 by SheetJS. Pass raw: true to XLSX.read to keep every value as text. More options, such as defval for empty cells, are in Excel to JSON in JavaScript.

Python, standard library only

Python's csv.DictReader uses the header row as keys and never guesses types, so every value is a string and leading zeros survive: 

import csv
import json

with open("people.csv", newline="", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

with open("people.json", "w", encoding="utf-8") as f:
    json.dump(rows, f, ensure_ascii=False, indent=2)

Empty cells come through as empty strings. Convert the columns that should be numbers yourself, for example int(row["id"]). ensure_ascii=False keeps accented letters readable instead of writing them as \u escapes.
