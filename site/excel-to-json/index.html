Excel to JSON converter online

Open a spreadsheet, pick a sheet and get its rows as a JSON array that you can copy or download. Each row becomes one object and the first row gives the keys. The file is read in your browser with SheetJS and is never uploaded.

How a sheet becomes JSON

  • The first row is the header. Every row under it turns into an object with those headers as keys.
  • Numbers and booleans stay numbers and booleans. Text stays text.
  • Date cells are written as ISO dates, for example "2026-11-02", or with a time when the cell has one.
  • Empty cells are left out of that row's object. Tick Write empty cells as null if every object should have every key.
  • A workbook with several sheets shows a sheet picker. Only the selected sheet is converted.
  • With the nested option on, a header like shipping.city becomes a nested object and a cell holding ["keyboard","mouse"] becomes a real array. That is the reverse of the JSON to Excel converter, so a file can make the round trip.

Excel to JSON in JavaScript

The converter is a small page around two SheetJS calls. In your own code, in Node.js or the browser, they look like this: 

import * as XLSX from 'xlsx';

const workbook = XLSX.read(fileBytes, { cellDates: true });
const sheet = workbook.Sheets[workbook.SheetNames[0]];
const rows = XLSX.utils.sheet_to_json(sheet, { UTC: true });

fileBytes is an ArrayBuffer, for example from await file.arrayBuffer() on a file input. cellDates turns date cells into Date objects instead of Excel serial numbers, and UTC keeps a date like 2 November from shifting a day in time zones east or west of UTC.

FAQ

How do I convert Excel to JSON?

Open the file with the box on this page, pick the sheet if the workbook has more than one, then copy the JSON or download it as a .json file. The first row of the sheet becomes the keys of every object.

Which file types can I convert?

.xlsx, .xlsm, .xlsb, the older .xls format, OpenDocument .ods and .csv. SheetJS reads all of them in the browser.

Is my spreadsheet uploaded?

No. The page is static and has no backend. Your browser reads the file and builds the JSON on your computer.

What happens to dates and empty cells?

Date cells become ISO strings such as 2026-11-02, with the time added when the cell has one. Empty cells are left out of the object unless you tick the option that writes them as null.

Can I get nested JSON back from a flat sheet?

Yes. Tick the nested option and a header such as shipping.city becomes {"shipping": {"city": ...}}, and cells that hold JSON text such as ["keyboard","mouse"] are parsed. That reverses what the JSON to Excel converter on this site writes.
